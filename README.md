Sales Analysis Dashboard – Excel

1. Project Overview

A sales data analysis project developed using Microsoft Excel to transform raw data into meaningful information. The dashboard focuses on analyzing sales performance, monitoring key performance indicators, identifying trends, and supporting data-driven decision-making.

2. Tools & Techniques

- Microsoft Excel: Data analysis and interactive dashboard development.
- Power Query: Data cleaning, transformation, and preparation.
- PivotTables: Data summarization, aggregation, and analysis.
- Excel Functions: Using formulas and functions to perform calculations and support data analysis.
- Interactive Slicers: Filtering data and exploring results across different dimensions.
- Data Visualization: Presenting KPIs, trends, and comparisons through clear visualizations.

3. Key Performance Indicators (KPIs)

- Total Sales.
- Total Orders.
- Total Transactions.
- Highest Sales by City.
- Highest Progressive Sales.
- Highest Sales by Region.
- Highest-Performing Sales Representative.

4. Dashboard Analysis

- Sales analysis by country.
- Monthly sales trend analysis.
- Sales analysis by payment type.
- Top 5 customers by sales.
- Sales performance by representative.
- Sales analysis by origin.
- Interactive exploration of sales performance using filters.

5. Project Features

- Data cleaning and preparation using Power Query.
- Data summarization and analysis using PivotTables.
- KPI monitoring through an organized dashboard.
- Interactive filtering for exploring sales data.
- Clear and structured data visualizations.
- Transforming raw data into meaningful insights to support business understanding and decision-making.

6. Project Objective

To demonstrate practical data analysis skills using Microsoft Excel, covering data cleaning, transformation, calculations, KPI analysis, and interactive dashboard development to generate useful insights into sales performance.
